Event-Space (Backend)
Это мой полигон для обкатки новых штук в NestJS и архитектуре. Проект писал с нуля: сам проектировал базу, поднимал докер и настраивал слои, чтобы код не превратился в кашу.

Что внутри:
NestJS + TypeOrm + PostgreSQL.
Docker: Сам собрал docker-compose, чтобы база и редис поднимались одной командой.
Redis: Прикрутил для кэша и быстрой работы с сессиями.
Транзакции: Прописывал вручную там, где важно, чтобы данные не разъехались (например, при покупке билетов, чтобы не купили больше чем было).
Тесты: Написал тесты, чтобы проверять, что логика не падает после каждого изменения.
